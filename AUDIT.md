# Аудит слайдов

Аудит — часть пайплайна. Узел `audit` графа LangGraph запускается после рендера и проверяет каждую колоду
без модели. Смысловую проверку моделью и исправления пользователь запускает из панели аудита в режиме
«Демонстрация». Найденное подсвечивается на слайде, пользователь отмечает, что исправить, и выбирает способ.
После исправления получается новая ревизия файла, и детерминированные проверки проходят заново.

| | Детерминированные | Контекстуальные (смысловые) |
|---|---|---|
| Что проверяют | Файл: координаты, размеры, цвета, шрифты, связи с макетами | Смысл: по картинке слайда, его тексту, брифу и материалам |
| Кто отвечает | Код, `backend/prism/audit/deterministic.py` | Модель: скиллы `slide_auditor`, `deck_auditor` (`backend/prism/audit/contextual.py`) |
| Повторный запуск | Тот же файл даёт тот же список находок | Ответ может отличаться |
| Когда | Автоматически после генерации и после каждого исправления | По кнопке «проверить смысл» в панели (около 20 с на колоду) |
| В интерфейсе | Тег группы: вёрстка, шаблон, плотность, целостность | Тег «смысл · модель» |

## Детерминированные проверки

Ориентир — Приложение 1 ТЗ. Проверки шаблона сравнивают файл со спецификацией шаблона (`TemplateSpec`):
его шрифтами, шкалой кеглей, палитрой, полями и макетами.

| Код | Группа | Что считается дефектом | Важность | Исправление |
|---|---|---|---|---|
| `off_slide` | вёрстка | текстовый блок выходит за край слайда больше чем на 1% | ошибка | вернуть в границы |
| `overlap` | вёрстка | тексты двух блоков перекрываются больше чем на 15% меньшего. Сравниваются области, где реально лежит текст (`ink_box`), а не рамки: рамки шаблона рисуют под длинный образец | замечание | сдвинуть нижний блок / ужать текст |
| `overflow` | вёрстка | текст выше рамки (метрики настоящих шрифтов, как при вёрстке) или слово шире строки. Если текст срезан краем слайда или налезает на соседний блок — ошибка | замечание / ошибка | уменьшить кегль по шкале / сократить текст (модель) |
| `margins` | вёрстка | блок, нарисованный вёрсткой (`prism:*`), заходит в поля шаблона | замечание | вернуть внутрь полей |
| `stretched_image` | вёрстка | пропорции рамки отличаются от видимой части картинки больше чем на 4% | ошибка | обрезать без искажения |
| `font_foreign` | шаблон | гарнитура не из шаблона | замечание | шрифт шаблона |
| `font_count` | шаблон | больше двух гарнитур на слайде | замечание | оставить шрифты шаблона |
| `size_off_scale` | шаблон | кегль не со ступени шкалы шаблона (допуск 0.6 pt) | замечание | привести к шкале |
| `small_font` | шаблон | кегль меньше 9 pt | замечание | увеличить до 9 pt |
| `color_off_palette` | шаблон | цвет текста или подложки `prism:*` не из палитры (ΔE ≥ 4) | замечание | ближайший цвет палитры |
| `contrast` | шаблон | контраст текста к фону под ним ниже 4.5:1 (для крупного текста — 3:1). Фон — ближайшая залитая фигура под текстом, иначе фон слайда или образца | замечание / ошибка < 3:1 | цвет с достаточным контрастом, ближайший к исходному |
| `layout_foreign` | шаблон | слайд на макете, которого нет в шаблоне | замечание | — |
| `bullets_count` | плотность | больше 6 пунктов в одном блоке | замечание | сократить список (модель) |
| `bullet_long` | плотность | пункт длиннее 15 слов | замечание | сократить пункты (модель) |
| `table_size` | плотность | больше 7 строк или 5 колонок | замечание | — |
| `chart_series` | плотность | больше 5 серий на диаграмме | замечание | — |
| `fill_ratio` | плотность | слайд занят меньше чем на 25% или больше чем на 75% (сетка 32×32). У титула, разделителя, цитаты и финала пустота — замысел, их не проверяем | замечание | — |
| `file_open` | целостность | файл не открывается | ошибка | — |
| `sample_text` | целостность | остался образец: `[…]`, «Заголовок», Lorem ipsum, XXX, TODO, «вставьте текст» | ошибка | удалить заглушку |
| `empty_slide` | целостность | пустой слайд или только заголовок (разделителю с одним тезисом можно) | ошибка | удалить слайд |
| `raster_slide` | целостность | слайд — одна картинка на весь слайд без текста и объектов | ошибка | удалить слайд |
| `chart_labels` | целостность | нет легенды при нескольких сериях, подписей долей у круговой, единиц на оси | замечание | добавить легенду и подписи |
| `duplicate_slide` | целостность | слова двух слайдов совпадают больше чем на 80% (Жаккар) | замечание | удалить повтор |
| `language` | смысл | больше трети слов слайда — на другом алфавите, чем колода (имена собственные с заглавной не считаются) | замечание | переписать на языке колоды (модель) |

Сокращения относительно Приложения 1, с обоснованием:
- **«Блоки не выровнены по направляющим макета».** Вёрстка ставит блоки только в слоты образца или на сетку полей шаблона, поэтому проверка всегда проходила бы. Направляющие шаблона используются при разборе (`tokens.guides`).
- **«Логотип или колонтитул сдвинуты».** Слайды клонируются из образцов шаблона. Логотип и колонтитул остаются на своих местах, вёрстка меняет в них только текст (номер слайда, название колоды).

## Контекстуальные проверки

Модель получает PNG слайда (80 dpi), его текст, бриф и материалы из интернета (`context.json` колоды) и
отвечает на вопросы «да/нет» из Приложения 1. На каждое «нет» она пишет причину, и эта причина становится
текстом находки. Логотипы, колонтитулы и декор шаблона — не мусор, это сказано модели в скилле.

| Вопрос ТЗ | Код | Исправление |
|---|---|---|
| 1. Заголовок содержит вывод, а не тему? | `conclusion_title` | переписать заголовок (модель) |
| 2. Содержимое соответствует заголовку? | `content_matches_title` | переписать текст (модель) |
| 3. Слайд пересказывается одним предложением? | `one_sentence` | сфокусировать текст (модель) |
| 4. Все цифры и факты есть в исходных материалах? | `facts_sourced` | убрать непроверенное (модель) |
| 5. Есть содержание, а не только заголовок? | `has_content` | удалить слайд / дописать (модель) |
| 6. Картинки и иконки по теме? | `visuals_relevant` | — (заменить картинку вручную) |
| 7. Нет служебного мусора? | `no_garbage` | убрать мусор (модель) |
| 8. Текст без опечаток? | `no_typos` | исправить опечатки (модель) |
| 9. Вся колода на одном языке? | `language` | проверяется детерминированно, см. выше |
| 10. Строки таблицы и легенда работают на мысль? | `data_serves_point` | переписать (модель) |
| 11. Соседние слайды связаны по логике? | `storyline` | добавить связку (модель) |

Вопросы 1–8 и 10 задаются по каждому слайду параллельно (до 6 запросов, роль `audit_vlm`), вопрос 11 — один раз
по текстам всей колоды (скилл `deck_auditor`).

## Исправления

Реализация — `backend/prism/audit/fixes.py`. Детерминированные исправления меняют геометрию, кегль по шкале шаблона, цвет, шрифт,
обрезку картинки, удаляют заглушки и слайды. Исправления моделью меняют **только текст существующих фигур**:

- `shorten` (скилл `text_shortener`) — сокращает до длины, которая влезает в рамку. Числа, даты и имена сохраняются.
- `rewrite` (скилл `slide_fixer`) — переписывает тексты слайда по списку замечаний. Факты берутся только из брифа и
  материалов. Каждая фигура сохраняет число абзацев, каждый абзац — не длиннее прежнего.

После правки текст снова подгоняется под рамку, файл перерисовывается и проходит детерминированные проверки заново.
Смысловые находки, которые исправлены, снимаются. Если удалялись слайды, смысловую проверку нужно запустить снова:
номера слайдов сдвинулись, и панель предлагает «проверить снова». Исходный файл вёрстки сохраняется как `deck.orig.pptx`.

## Где что лежит

| | |
|---|---|
| `backend/prism/audit/deterministic.py` | детерминированные проверки |
| `backend/prism/audit/contextual.py` | смысловые проверки |
| `backend/prism/audit/fixes.py` | исправления |
| `backend/prism/audit/service.py` | состояние аудита варианта (`audit.json`), ревизии, журнал исправлений |
| `backend/app/audit.py` | API панели: `GET …/audit/{template}/{variant}`, `POST …/contextual`, `POST …/fix` |
| `frontend/AuditPanel.tsx` | панель в интерфейсе |
| `backend/skills/{slide_auditor,deck_auditor,text_shortener,slide_fixer}/v1.yaml` | промпты |
| MCP `pptx`: `audit_deck`, `render_slide`, `set_shape_text` | те же проверки и правки как инструменты для агентов |
| `backend/tests/test_audit.py`, `test_decks_api.py` | тесты: дефекты находятся, выбранные исправления их убирают, API панели |

Запуск из консоли: `python -m prism.audit.deterministic <deck.pptx>`.
